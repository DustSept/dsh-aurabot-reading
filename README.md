# Aurabot 读书看报

给 [Aurabot](https://github.com/accomplish07zrh-eng/dsh-aurabot-qq)（大肥鱼）加一个「读书看报」模块：书架、随机阅读、进度、读后感、主动分享、RSS 热点、收主人发的 txt、去公共版权书库找书。

模块 ID：`reading` · 扩展接口：v1 · 版本：1.0.0

## 功能

- **接收 txt / md**：在 QQ 私聊里发文件，自动下载进书架；支持 UTF-8、GBK、UTF-16LE/BE。
- **书架和进度**：每本书记录读到哪、读了百分之多少、历次感想。
- **随机阅读**：每天在设定时段内，按随机间隔读随机长度；不是固定打卡。
- **读后感**：读完一段用她自己的口气写一两句，存进笔记，聊天时会想起来。
- **主动分享**：按概率把读后感/新闻感想发给主人；主人在忙时只存不发。
- **看热点**：抓取 RSS 标题和摘要，像刷手机一样先反应，不播报新闻。
- **收文章链接**：把网页正文抓进书架，慢慢读。
- **自己找书**：Project Gutenberg（英文公共版权）；中文维基文库在部分网络环境连不上，建议直接发 txt。
- **收书反应**：收到新书先像人一样惊喜/好奇、猜体裁、评论书名或想象封面、联想读过的书；不报字数，不发“已放上书架”。

## 安装

需要 Windows、Aurabot 1.0.5+（扩展接口 v1）。

1. 把本仓库的 `reading` 文件夹整个复制到：

   ```
   %USERPROFILE%\.dsh\plugins-data\aurabot\modules\reading
   ```

   正确结构：

   ```
   modules\reading\index.mjs
   ```

2. 等几秒，Aurabot 会自动加载。打开面板「扩展」页，应该能看到「读书看报」在跑。

3. 打开「读书看报」设置页，把「开关」打开。

4. （推荐）把 [`persona/reading-section.md`](persona/reading-section.md) 粘到人格卡里。模块本身能用，但人格里这段会让她的语气更像在读书。

## 使用

在**主人私聊**里：

- 直接发 `.txt` / `.md` 文件：她会收进书架并先对书做出反应。
- `/读书`：看书架、进度、今天的阅读次数。
- `/读书 next`：读下一段。
- `/新闻`：看几条热点标题。
- 说“找本短一点的书看看”：她会用 `reading_find` 去公共版权书库找。
- 发一个文章链接并说“看看这篇”：她用 `reading_add_url` 收进书架并说第一反应。

她也能自己调用这些工具：`reading_shelf`、`reading_open`、`reading_next`、`reading_note`、`reading_news`、`reading_add_url`、`reading_find`。

## 设置

面板「读书看报」页：

| 设置 | 默认 | 说明 |
|---|---|---|
| 开关 | 关 | 打开后才会自动读和主动分享 |
| 每次阅读最少/最多字 | 600 / 1800 | 每次随机取一个长度 |
| 两次阅读最短/最长间隔（分钟） | 60 / 180 | 频率；不是固定时间 |
| 每天最多自动读几次 | 8 | `0` = 不限 |
| 读后感主动分享概率 | 0.35 | 0 到 1 |
| 每天最多主动分享几次 | 3 | `0` = 不主动分享 |
| 看新闻的比例 | 0.35 | `0` = 只读书，`1` = 只看新闻 |
| 新闻感想主动分享概率 | 0.3 | 0 到 1 |
| 看热点新闻 | 开 | 关掉后只读书 |
| RSS 源 | IT之家 / 少数派 / 中国新闻网 | 一行一个，可换成自己的 |
| 几点开始/以后不读 | 8 / 23 | 睡眠时段不读 |
| 接收 txt 最大 MB | 20 | 超过会拒绝 |

## 数据位置

```
%USERPROFILE%\.dsh\plugins-data\aurabot\modules-data\reading\
  books\          书和文章（txt / md）
  state.json      进度、笔记、下次阅读时间
```

这些是**本机个人数据**，不要提交到仓库或分享给别人。升级模块不会删它们。

## 自动阅读规则

- 只在 `几点开始读` 到 `几点以后不读` 之间。
- 每次读随机长度，更新进度。
- 有书时按「看新闻比例」决定读书还是看新闻；没书就看新闻。
- 每天最多自动读 `maxPerDay` 次；到达上限后排到第二天。
- 读完写一两句感想；按分享概率主动发给主人，但主人 20 分钟内刚聊过就不打断。
- 尊重 Aurabot 总开关、试运行、闭嘴和免打扰时段。

## 兼容与依赖

- Aurabot 扩展接口 v1；Aurabot 1.0.5+。
- 只用 Node 自带模块，**没有 npm 依赖**。
- 使用 Aurabot 的 `api.think()` 生成读后感，会消耗模型额度。
- 使用 Node 全局 `fetch` 抓 RSS/文章，需要网络。
- 文件接收走 SnowLuma 的 `get_private_file_url`；不支持时会把书架路径告诉你，手动拷贝即可。

## 已知限制

- 只收 `.txt` / `.md`；PDF、EPUB 请先转成 txt。
- 中文公共版权书源（维基文库）在部分网络环境连不上；中文书建议直接发 txt。
- 只处理主人私聊里的文件；群文件、别人发的文件不处理。
- RSS 源和网页结构会变，抓不到时看日志里的 `reading` 段。
- 工具只在主人私聊里注册，群聊没有文件/网络工具。

## 安全

用户模块运行在 Aurabot 进程里，拥有文件、网络和调用 OneBot 的权限。安装前请自己读一遍 `reading/index.mjs`；不要安装来源不明的模块。

模块本身不包含任何 API Key、QQ 号或聊天数据。
